# Prompt alat za Standard Galactic Alphabet (SGA)

Ovaj predložak koristi se za pretvaranje teksta u Standard Galactic Alphabet,
poznat i kao pismo s Minecraft enchanting tablice. Najbolje radi kada AI može
ispisati SGA Unicode znakove, koristiti SGA font ili izraditi sliku.

## Osnovni prevoditelj

```text
Ponašaj se kao precizan prevoditelj za Standard Galactic Alphabet (SGA).
Pretvori sljedeći tekst u SGA:

[TEKST]

Pravila:
- slova prevodi redom, bez mijenjanja riječi ili značenja
- zadrži razmake, retke, brojeve i interpunkciju osim ako zatražim drukčije
- ne dodaj objašnjenja unutar prevedenog teksta
- ako neki znak nema jasnu SGA zamjenu, ostavi ga nepromijenjenog i navedi ga
  nakon prijevoda u kratkoj napomeni
- nakon SGA verzije prikaži i izvornu latinicu radi provjere

Ispis oblikuj ovako:
SGA: [prijevod]
Latinica: [izvorni tekst]
Napomena: [samo ako je potrebna]
```

## Verzija za sliku ili poster

```text
Pretvori tekst [TEKST] u Standard Galactic Alphabet (SGA) i pripremi dizajn za
[POSTER/NALJEPNICU/MAJICU/SLIKU].

Vizualni smjer: [minimalistički / Minecraft enchanting table / svemirski /
retro-futuristički].
Boje: [BOJE]. Pozadina: [POZADINA]. Format: [DIMENZIJE].

Prvo ispiši točan SGA prijepis i latinicu radi provjere. Zatim izradi samo
vizual s provjerenim SGA tekstom. Nemoj dodavati nove riječi ni mijenjati
pravopis izvornog teksta.
```

## Dvosmjerna provjera prijevoda

```text
Želim provjeriti SGA poruku. Odradi sljedeće korake:
1. Pretvori latinicu [TEKST] u Standard Galactic Alphabet.
2. Zatim prevedi dobiveni SGA natrag u latinicu.
3. Usporedi povratni prijevod s izvornim tekstom.

Ako postoji razlika, jasno navedi problematični znak i predloži ispravak.
Ne izmišljaj znakove kada mapiranje nije sigurno; označi takve slučajeve kao
"potrebna ručna provjera".
```

## Brza varijanta

```text
Pretvori u Standard Galactic Alphabet (SGA), uz potpuno očuvanje razmaka,
brojeva i interpunkcije: [TEKST]
```

## Napomena o fontu

Ako rezultat treba prikazati kao font, može se koristiti SGA font. Nemoj
mijenjati sistemski font operacijskog sustava; koristi font samo u dokumentu,
slici ili pojedinoj aplikaciji.
